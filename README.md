## 🍴 Canteen Management System Website

This is a simple **Canteen Management System Website** built using HTML, CSS, and JavaScript.  
It allows customers, admins, and support teams to interact with the system through different pages.
This Website totally build by Our Skill-X Dynamic Group (Team Member: kumaresh Jana, Zabed Khan, Sattik Pahari, Hritwik Mondal, Akash Khan).

---

## ✨ Features

- 🏠 **Home Page** (`index.html`) – Entry point for users  
- 👨‍💼 **Admin Panel** (`admin.html`) – Manage menu, orders, and users  
- 👤 **Customer Page** (`customer.html`) – View menu and place orders ( ⚠️Work in Progress )
- 💬 **Support Page** (`support.html`) – Get help or contact support
